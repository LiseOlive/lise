# <font color="#9bbb59">Chapitre 1 - Le comportement de consommation des ménages</font>


> [!question]
> *Qu'est-ce qui peut expliquer la C (consommation finale) des ménages ?*


## <font color="#9bbb59">L'explication Keynésienne</font>

Selon Keynes, la consommation est déterminée par : 

- le Revenu Disponible des Ménages : le revenu national - les taxes $$Y^{disp} = Y - T
$$
- une Propension Marginale à Consommer

Quand on augmente le revenu disponible des ménages, ces derniers augmentent leur niveau de consommation d'un montant inférieur au supplément de revenu obtenu.
Par exemple, si Y<sup>disp</sup> augmente de 100, la consommation augmente de 80

> [!important] La fonction de consommation keynésienne prend la forme
> $$C = C_{O}+_{C}\times Y^{disp} 
> $$


C<sub>O</sub> : Niveau de consommation autonome (ne dépend pas de Y)

<sub>C</sub> : Propension marginale à consommer
$$
0 < _{C} < 1 
$$
<sub></sub>
> [!example]
> C = 30 + 0,75 · Y<sup>disp</sup>
> 
> Si Y<sup>disp</sup> = 0 → C = 30 + 0,75 · 0 = 30
> Si  Y<sup>disp</sup> = 200 → C = 30 + 0,75 · 200 = 180
> 
> Si Y<sup>disp</sup> = 201 → C = 30 + 0,75 · 201 = 180,75
> 
> Le revenu disponible augmente de 1 unité, les ménages augmentent leur consommation de 0,75 (< 1)



![[Screenshot 2026-01-20 at 20.49.33.png\|Screenshot 2026-01-20 at 20.49.33.png]]


Puisque <sub>C</sub> est constant, la fonction a la forme d'une droite.

On verra par la suite que <sub>C</sub> a un effet fondamental sur l'efficacité des politiques économiques.

> [!example] Deuxième exemple
> C = 40 + 0,75 · Y<sup>disp</sup>
> 
> Si  Y<sup>disp</sup> = 0 ➞ C = 40
> Si  Y<sup>disp</sup> = 200 ➞ C = 150
> Si  Y<sup>disp</sup> = 201 ➞ C = 190,75


> [!example] Troisième exemple
> C = 30 + 0,9 · Y<sup>disp</sup>
> 
> Si  Y<sup>disp</sup> = 0 ➞ C = 30
> Si  Y<sup>disp</sup> = 200 → C = 210
> Si  Y<sup>disp</sup> = 201 → C = 210,9



![[Screenshot 2026-01-20 at 20.52.00.png\|Screenshot 2026-01-20 at 20.52.00.png]]


・La propension marginale à consommer est souvent notée :
$$P_{M} C
$$


> [!abstract]
> ・Il existe aussi la propension moyenne à consommer, notée PMC, qu'on calcule :
>  $$
> PMC = \frac{C}{Y^{disp} } =    \frac{C_{O}  + _{C}  \times  Y^{disp}}{Y^{disp} } = \frac{C_{O}}{Y^{disp}}  + \frac{_{C}  \times  Y^{disp} }{Y^{disp}} 
> $$
> $$PMC = \frac{C_{O} }{Y^{disp} }  + _{C} 
> $$


Reprenons la première fonction de C<sub>O</sub> : C = 30 + 0,75 · Y<sup>disp</sup>

Si Y<sup>disp</sup> = 100 ➞ C = 105 ➞ PMC = 105/100 = 1,05  
Si Y<sup>disp</sup> = 200 ➞ C = 180 ➞ PMC = 180/200 = 0,9  
Si Y<sup>disp</sup> = 1000 ➞ C = 780 ➞ PMC = 780/1000 = 0,78

La PMC diminue quand Y<sup>disp</sup> augmente,  
Elle se rapproche alors de P<sub>M</sub>C

## <font color="#9bbb59">Les autres propositions pour expliquer la consommation des ménages</font>


### <font color="#9bbb59">Duesenberry et Modigliani</font>

・Vont expliquer les habitudes de consommation, et l'**effet cliquet**

![[Screenshot 2026-01-22 at 13.41.47.png\|Screenshot 2026-01-22 at 13.41.47.png]]


1. Entre t=0 et t=1, Y<sup>disp</sup> augmente et la consommation aussi  
		⤷ d'accord avec Keynes

2. Entre t=1 et t=2 le Y<sup>disp</sup> revient à son niveau initial  
		⤷ **la consommation va diminuer mais ne va pas retrouver son niveau initial, elle va moins diminuer qu'elle n'avait augmenté**

> [!abstract]
> $$
> C=C_{O}+f(Y^{disp}_{t}, Y^{disp}_{t-1})
> $$

⇒ La consommation à la date t dépend du revenu disponible à la date t et aussi à la date t-1


### <font color="#9bbb59">L'approche classique de Fisher : le choix inter-temporel</font>

・Les ménages font un arbitrage Consommation vs Épargne en fonction du Taux d'intérêt.
$$ C=f(Y^{disp}_{actuel}, Y^{disp}_{futur}, Tx d'interet)
$$

### <font color="#9bbb59">La théorie du cycle de vie - Modigliani</font>

・Le comportement de consommation dépend de l'âge de l'individu  
	⤷ Modèle de type *Générations Imbriquées*
