# Faute contraventionnelle

Est reprise dans [[l'art. 121-3 al. 5 du Code Pénal\|l'art. 121-3 al. 5 du Code Pénal]] 

La faute contraventionnelle est présumée force majeure

> [!info] Force majeure
> - Irrésistible
> - Imprévisible
> - Toujours présumée
