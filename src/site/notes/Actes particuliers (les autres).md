# Actes particuliers (décisions d'espèce)

> [!abstract] Définition
> Actes administratifs unilatéraux décisoires qui ne sont **ni réglementaires** (ils ne fixent pas de règle générale et abstraite permanente) **ni individuels** (ils ne désignent pas nommément de personnes identifiées). Le code les qualifie de *« décisions ni réglementaires ni individuelles »* (art. L. 200-1 du [[CRPA - Code des relations entre public et administration - 1er janvier 2016\|CRPA]]).

## Exemples caractéristiques :
- **Déclaration d'Utilité Publique (DUP)** dans le cadre d'une procédure d'expropriation pour cause d'utilité publique.
- **Arrêté d'ouverture d'un concours** administratif de recrutement dans la fonction publique.
- **Délibérations de collectivités territoriales** approuvant le principe d'une opération d'aménagement ou modifiant l'assiette d'un service public.
